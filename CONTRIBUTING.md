# Contribuir

Gracias por considerar contribuir a AI Screen Assistant.

## Proceso

1. Abre un issue para describir errores o cambios grandes antes de empezar.
2. Crea una rama con un nombre descriptivo.
3. Mantén los cambios enfocados y explica cualquier cambio de comportamiento.
4. Abre un pull request con el problema, la solución y los pasos usados para comprobarla.

## Desarrollo local

Usa un entorno virtual y las dependencias de `requirements.txt`. Ollama y un modelo multimodal compatible son necesarios para probar el flujo completo. No incluyas capturas con información personal, credenciales, archivos del entorno virtual ni datos locales en tus commits.

## Licencia

Al enviar una contribución, aceptas que se distribuya bajo los términos de la licencia MIT de este proyecto.
